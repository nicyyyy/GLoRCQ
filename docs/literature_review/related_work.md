# 2 Related Work

The compression of large language models (LLMs) into low-bit representations has evolved rapidly along several complementary tracks. GLoRCQ sits at the intersection of low-bit post-training quantization (PTQ), low-rank residual compensation, and Mixture-of-Experts (MoE) specialization. This section surveys the prior art along six axes: scalar PTQ, vector quantization, LoRA-augmented quantization, MoE-specific quantization, outlier/mixed-precision handling, and MoE inference systems. Each subsection identifies the specific limitations that motivate the design choices of GLoRCQ.

## 2.1 Scalar PTQ for LLMs

Scalar (per-element) post-training weight quantization has been the workhorse of LLM compression, primarily because it maps cleanly to integer tensor cores and imposes minimal changes on the serving stack. The seminal contribution in this space is GPTQ (Frantar et al., 2023), which formulates weight quantization as a layer-wise reconstruction problem and solves it column-by-column with second-order (Hessian-based) error compensation. GPTQ demonstrated that 175B-parameter models could be pushed to 3–4 bits in a few GPU-hours with only marginal degradation, and it remains the algorithmic backbone that GLoRCQ builds on for its scalar-quant baseline. A recent theoretical analysis (Chen et al., 2025) recasts GPTQ back-to-front as Babai's nearest-plane algorithm on a Hessian-defined lattice, providing an error bound that motivates clip-free variants and grounds why GPTQ-style error propagation is nearly optimal among greedy schemes.

Parallel to error-compensated rounding, a second family of scalar methods focuses on redistributing the difficulty of quantization across the network. SmoothQuant (Xiao et al., 2022) introduces a mathematically equivalent per-channel scaling transform that migrates activation outliers into weights, unlocking W8A8 quantization without retraining. AWQ (Lin et al., 2023) sharpens the same idea for weight-only PTQ by preserving the ~1% of salient channels identified through activation magnitudes, pairing it with the TinyChat inference kernels for hardware efficiency. SmoothQuant+ (Pan et al., 2023) extends the migration principle to 4-bit weight-only PTQ and integrates it into vLLM. OmniQuant (Shao et al., 2023) adds learnable weight clipping and learnable equivalent transformations optimized via block-wise reconstruction, spanning both weight-only and weight-activation settings.

A third strand attacks activation outliers geometrically. SpinQuant (Liu et al., 2024) learns Cayley-parameterized rotation matrices that redistribute outliers across weight and activation channels for W4A4KV4. QuaRot (Ashkboos et al., 2024) applies Hadamard rotations in a computationally invariant fashion, showing that end-to-end 4-bit LLM inference is possible without retaining any high-precision channels. ButterflyQuant (Xu et al., 2025) replaces fixed Hadamard rotations with learnable orthogonal butterfly transforms parameterized by Givens rotation angles, providing layer-adaptive outlier suppression at O(n log n) cost. QServe (Lin et al., 2024) approaches the same problem through a co-designed W4A8KV4 pipeline (QoQ), showing that dequantization overhead — not arithmetic — is the real bottleneck for LLM serving. PrefixQuant (Chen et al., 2024) sidesteps token-wise outliers entirely by isolating them into prefixed KV positions, enabling static W4A4KV4.

At the ultra-low-bit frontier, TesseraQ (Li and Panda, 2024) uses block-reconstruction with progressive adaptive rounding (soft-to-hard) and dequant-scale optimization to push sub-3-bit weight quantization, and it can be layered on top of AWQ or OmniQuant. Sharify et al. (2024) systematically combine SmoothQuant, AWQ, and GPTQ with microscaling (MX) block formats. Matryoshka Quantization (Nair et al., 2025) trains a single int8 model whose most-significant bits also serve as valid int4/int2 quantizations, offering elastic precision at serving time.

Despite this rich toolkit, all of these methods share two blind spots that GLoRCQ targets. First, they view a Transformer layer as a homogeneous weight matrix — none exploit the block-diagonal structure of MoE experts or the abundant redundancy across experts and layers. Second, at sub-2-bit budgets, per-element rounding alone loses more accuracy than any of these preprocessing tricks can recover; a rank-r residual compensator becomes necessary. GLoRCQ retains GPTQ-style error-compensated rounding as its scalar-quant backbone but attaches a globally shared low-rank residual on top of it, and it further specializes the pipeline for the routing sparsity of MoE.

## 2.2 Vector-quantization LLMs

When bit budgets fall below two bits per weight, scalar quantization runs into the fundamental limit that a single value cannot encode enough information per weight. Vector quantization (VQ) sidesteps this limit by encoding tuples of weights against a shared codebook, exploiting the "blessing of dimensionality." AQLM (Egiazarian et al., 2024) generalizes classical additive quantization to LLM weights: each block of weights is represented as a sum of entries drawn from several learned codebooks, and the codebooks are jointly optimized per Transformer block. AQLM demonstrates Pareto-optimal accuracy at 2–3 bits and remains a canonical dense-LLM baseline. QuIP# (Tseng et al., 2024) combines randomized Hadamard incoherence processing with hardware-efficient E8-lattice codebooks and light fine-tuning, achieving state-of-the-art results at 2 bits on dense LLMs.

GPTVQ (van Baalen et al., 2024) directly hybridizes VQ with the GPTQ backbone: it extends Hessian-aware error compensation to non-uniform vector quantization and updates codebooks jointly with EM. Its empirical finding — that accuracy improves systematically as codebook dimension grows — is a key data point that motivates GLoRCQ's tile-quantization design, in which multiple weights within a tile share a codeword. VPTQ (Liu et al., 2024) refines the same theme with channel-independent second-order optimization, a lightweight codebook initialization derived from an optimization decomposition, and extensions for residual and outlier quantization. CCQ (Xu et al., 2025) replaces codebook lookups with a bit-shift convolutional-code encoding, delivering 2.0–2.75-bit compression on both dense LLMs and MoE models such as DeepSeek-V3 and ERNIE-4.5-A47B while eliminating the memory-bandwidth cost of table lookups.

Two additional works push the extremes. OneBit (Xu et al., 2024) reduces each linear layer to a sign matrix plus two FP16 value vectors and uses knowledge distillation to recover accuracy, showing that 1-bit LLM inference is feasible at the cost of QAT and distillation. PTQ1.61 (Zhao et al., 2025) targets an average of 1.61 bits per weight by combining a structured salience-aware mask (which reserves higher-bit codebooks for salient columns) with binary quantization on the remaining weights and a block-wise error-compensation reconstruction procedure. Gao et al. (2024) propose Learnable Singular value Increment (LSI), an SVD-based error-compensation technique in which learnable singular values allow weights to compensate each other's quantization errors conditioned on activations — conceptually adjacent to the low-rank residual view we adopt later.

These VQ methods establish two lessons that GLoRCQ inherits. First, at sub-2-bit budgets, grouped/vectorized encoding dominates per-element rounding; this justifies the VQ4 tile-quantization variant we build. Second, most existing VQ methods treat codebook construction as a per-layer or per-block problem: the codebook of layer i's up-projection is unrelated to layer j's. In MoE, where dozens of experts across dozens of layers all quantize matrices with similar spectral structure, this per-block scoping is wasteful. GLoRCQ instead shares low-rank compensation factors across groups of experts drawn from different layers, allocating bit budget more efficiently than a per-block codebook can.

## 2.3 Low-rank / LoRA-based quantization

The idea of decomposing a full-precision weight as W ≈ Q + AB — a low-bit quantized backbone Q plus a low-rank correction AB — has emerged as one of the most reliable ways to recover accuracy at extreme low-bit budgets, and it is the direct methodological ancestor of GLoRCQ. The low-rank parameterization itself traces back to LoRA (Hu et al., 2021), which introduced ΔW = BA as a parameter-efficient adaptation of frozen pretrained weights. LoRA established that Transformer weight updates lie approximately in a low-rank subspace — a property that also holds, empirically, for quantization residuals.

QLoRA (Dettmers et al., 2023) fused the two ideas by finetuning trainable LoRA adapters through a frozen 4-bit NF4 backbone. QA-LoRA (Xu et al., 2023) added group-wise operators that let the trained adapter be merged back into the quantized weights without accuracy loss. IR-QLoRA (Qin et al., 2024) refines information retention through statistics-based Information Calibration Quantization and a parameter-free Information Elastic Connection, delivering strong 2–4-bit results in the LoRA-finetuning setting.

The line of work most directly relevant to GLoRCQ, however, initializes rather than finetunes the low-rank component. LoftQ (Li et al., 2023) jointly initializes the quantized backbone and LoRA adapters so that Q + AB approximates the full-precision W in Frobenius norm — a "quantization-aware initialization" that also happens to be a valid PTQ scheme when the adapters are kept fixed. LQ-LoRA (Guo et al., 2023) generalizes this into an iterative decomposition W = LR + Q with an integer-linear-program allocator for mixed-precision bit widths and block sizes, and it optionally weights the reconstruction objective by Fisher information. ApiQ (Liao and Monz, 2024) minimizes activation reconstruction error rather than weight error when jointly initializing quantization scales and LoRA adapters — a viewpoint that GLoRCQ largely inherits. L4Q (Jeon et al., 2024) jointly optimizes quantization scales/steps together with the low-rank adapter, blurring the boundary between PTQ initialization and QAT.

LQER (Zhang et al., 2024) is arguably the closest methodological analogue to GLoRCQ: it compensates the quantization residual W − Q by an activation-weighted SVD, choosing the low-rank basis so as to minimize the reconstruction error on real activations rather than raw weight error. GLoRCQ shares LQER's activation-weighted decomposition but departs from it in two ways: (i) the low-rank U factor is *shared* across a group of experts (potentially from different layers), and (ii) the residual is optimized jointly with the GPTQ backbone in an alternating scheme rather than one-shot SVD. SpQR (Dettmers et al., 2023) belongs to the same "backbone + sparse residual" family; it isolates outlier weights into a small sparse high-precision component alongside 3–4-bit dense weights. Structurally, SpQR's sparse residual is a rank-∞ but position-sparse correction, whereas GLoRCQ uses a dense but rank-r correction — the two are complementary. Gao et al. (2024) push in the same direction via learnable singular values.

Finally, a related but tangential thread targets parameter-efficient finetuning via Fourier or spectral decomposition (Zhang et al., 2024, "QLoRA-FA"): it treats ΔW as a spatial-domain matrix and learns only a small fraction of its DFT coefficients. While not itself a quantization method, it demonstrates that alternatives to standard LoRA exist for parameterizing low-rank-like updates.

Two limitations of the LoRA-quantization line motivate GLoRCQ. First, essentially every existing method treats each weight matrix in isolation: each layer of each expert receives its own private low-rank pair (A, B), so the rank budget cannot be pooled. In an MoE with 128 experts, this either forces very small per-expert ranks (limiting accuracy) or blows the parameter budget. Second, none of these methods exploits the fact that different experts (and different layers' experts) frequently span similar low-rank subspaces, so their (A, B) factors are highly correlated. GLoRCQ addresses both by sharing the U factor of the low-rank residual across a group of experts drawn from different layers, effectively amortizing the rank budget across the MoE.

## 2.4 MoE-specific quantization

Mixture-of-Experts models pose a distinctive quantization challenge. Their weight matrices are dominated by expert FFNs, which account for the vast majority of parameters but see only sparse, routing-dependent activation. Naïvely applying dense-LLM PTQ methods to MoE either wastes bit budget on rarely activated experts or destroys accuracy on the few hot experts. The MoE-specific line has therefore developed its own set of techniques.

MoQE (Kim et al., 2023) provides the earliest large-scale evidence that MoE experts are unusually robust to aggressive sub-4-bit weight-only quantization — sometimes even improving quality due to a regularization effect — while dramatically reducing memory. This finding underwrites the current wave of MoE-quantization research: because expert weights tolerate more aggressive compression than shared attention weights, they are the natural target for sub-2-bit methods. EAQuant (Fu et al., 2025) builds on this observation with an expert-aware PTQ pipeline that jointly handles expert-level sparse activation, routing consistency across quantized experts, and expert-specific activation outliers. MxMoE (Duanmu et al., 2025) instead attacks inter-expert heterogeneity via mixed precision: per-expert bit widths are allocated according to weight sensitivity and activation frequency, and dedicated GPU kernels support the resulting mixed-precision layout. CCQ (Xu et al., 2025), discussed above, demonstrates convolutional-code VQ on MoE backbones including DeepSeek-V3.

The two most methodologically similar prior works are MiLo and TileQ. MiLo (Huang et al., 2025) — Mixture of Low-Rank Compensators — augments 3-/4-bit quantized MoE experts with a small mixture of low-rank compensators to recover accuracy lost to aggressive quantization, and pairs the design with a fused Tensor-Core GEMM kernel for efficient inference. MiLo's compensators are per-expert, meaning that at very tight budgets the rank per expert becomes vanishingly small. TileQ (Gu et al., 2026) introduces 2D tile quantization together with per-expert LoRA correction, achieving strong sub-2-bit accuracy on Mixtral and Qwen-MoE while enabling fused-kernel inference. TileQ is the direct experimental predecessor of GLoRCQ.

**Positioning of GLoRCQ.** GLoRCQ sits at the confluence of these three lines. From TileQ we inherit the 2D tile-quantization backbone and the per-expert LoRA correction architecture. From MiLo we inherit the observation that a low-rank compensator on top of aggressively quantized MoE experts is the right locus of accuracy recovery. From the LoRA-quantization line (LoftQ, LQER, LQ-LoRA) we inherit the joint quantization + low-rank decomposition W ≈ Q + AB with activation-weighted objectives. What distinguishes GLoRCQ is two-fold. First, we share the U (up-projection) factor of the LoRA compensator across a group of experts drawn from *different Transformer layers* — a global, cross-layer basis pool that amortizes the low-rank budget across the entire MoE rather than allocating it independently per expert. Under the same total bit budget, this cross-layer sharing yields a strictly larger effective rank per expert and a strictly better reconstruction. Second, we add an implicit outlier fallback: experts whose maximum reconstruction error exceeds a threshold τ are retained in FP16, so the pathological experts that would otherwise dominate perplexity are removed from the quantization pool without any explicit routing modification. Together, cross-layer U sharing and outlier fallback deliver a fair-bit win over TileQ Table 1 (2-bit + 0.16 extra bits) on Qwen1.5-MoE, Mixtral, and Qwen3-30B-A3B.

## 2.5 Outlier and mixed-precision quantization

Outlier handling is arguably the single most-studied problem in LLM quantization, because a small number of channels or tokens with abnormally large magnitudes dominate the reconstruction error at low bit widths. Two broad strategies have emerged. The first *transforms* the weights so that outliers are absorbed elsewhere or spread out: SmoothQuant (Xiao et al., 2022) and its 4-bit descendant SmoothQuant+ (Pan et al., 2023) migrate activation-side outlier magnitude into weights; AWQ (Lin et al., 2023) protects salient channels through activation-aware scaling; SpinQuant (Liu et al., 2024), QuaRot (Ashkboos et al., 2024), and ButterflyQuant (Xu et al., 2025) rotate the weight and activation space (with fixed Hadamard, learned Cayley, or learned butterfly transforms respectively) so that outlier energy is redistributed. PrefixQuant (Chen et al., 2024) isolates outlier *tokens* rather than channels by pre-caching them in the KV cache.

The second strategy explicitly *carves out* the outliers into a higher-precision component. SpQR (Dettmers et al., 2023) is the archetype: it stores the outlier weights in a small sparse FP16 tensor while quantizing the bulk to 3–4 bits, achieving near-lossless compression with modest inference overhead. VPTQ (Liu et al., 2024) supports residual and outlier codebooks; MxMoE (Duanmu et al., 2025) allocates higher bit widths to sensitive experts. This carve-out family is the closest structural precedent for the outlier fallback in GLoRCQ.

GLoRCQ adopts a minimalistic form of the carve-out strategy adapted to MoE routing. Because MoE experts are activated sparsely, the marginal memory cost of retaining a handful of pathologically-quantized experts at FP16 is small, while the perplexity benefit is large. Specifically, after joint optimization of the quantized backbone Q and the shared LoRA compensator (U, V), any expert whose maximum reconstruction error ||W − Q − UV||_∞ exceeds a threshold τ is reverted to FP16. This is *implicit* mixed precision — the fallback set is discovered by the reconstruction procedure, not prescribed by an external allocator like MxMoE. It is also *coarse-grained* — we fall back entire experts rather than individual channels — which keeps kernel dispatch simple, unlike SpQR's fine-grained sparse index.

Two properties distinguish this fallback from prior mixed-precision MoE work. First, it is threshold-driven and hyperparameter-cheap: a single τ controls the trade-off between accuracy and expected FP16 footprint. Second, it interacts multiplicatively with the shared low-rank compensator: the LoRA residual removes the "easy" component of the quantization error, and only genuinely irreducible experts trip the τ threshold. In our experiments, the fp16 fallback rate is a small single-digit percentage of experts and yields a disproportionately large PPL improvement.

## 2.6 MoE inference systems and decode acceleration

Accuracy-preserving quantization is only half of the value proposition; realizing memory and latency savings at inference is the other half. QServe (Lin et al., 2024) demonstrates on dense LLMs that dequantization overhead — not arithmetic — is the dominant cost of W4A8KV4 inference, and it introduces compute-aware weight reordering and register-level parallelism to hide it. TinyChat, released alongside AWQ (Lin et al., 2023), similarly emphasizes hardware-friendly kernels for W4A16 GEMMs. Both make clear that a quantization scheme is only as good as its serving kernels.

For MoE specifically, MiLo (Huang et al., 2025) contributes a fused Tensor-Core GEMM that jointly consumes the 3-/4-bit quantized expert weights and the small low-rank compensators — a design pattern that GLoRCQ builds on. CCQ (Xu et al., 2025) integrates its convolutional-code encoding into an efficient lookup-free kernel. MxMoE (Duanmu et al., 2025) provides mixed-precision expert kernels that handle heterogeneous per-expert bit widths.

GLoRCQ contributes to this system layer in two ways. First, we implement VQ4 tile quantization with a fused CUDA kernel that consumes the 2-bit tile codes and applies the shared LoRA compensator in the same pass; the cross-layer U pool is stored once in shared memory across the whole MoE forward pass, avoiding repeated loads. Second, the fp16 fallback experts share a common dispatch path with the quantized experts by routing them through a runtime selector — the router itself is not modified. Empirically, this design keeps decode-time throughput competitive with dense fp16 baselines while realizing the memory savings of sub-2-bit quantization. However, we emphasize (following the vLLM-fp16 baseline established in our own measurements) that memory saving — not raw throughput — remains the primary practical benefit; matching a mature fp16 kernel like vLLM's on absolute tokens/second is a distinct systems problem.

## 2.7 Summary and Positioning

GLoRCQ synthesizes and extends four immediate predecessors, one per major axis. GPTQ (Frantar et al., 2023) supplies the Hessian-based error-compensated scalar-quantization backbone. LQER (Zhang et al., 2024) and LQ-LoRA (Guo et al., 2023) establish the W ≈ Q + AB decomposition with activation-weighted low-rank compensation on dense LLMs. MiLo (Huang et al., 2025) shows that per-expert low-rank compensators recover accuracy on aggressively quantized MoE. TileQ (Gu et al., 2026) contributes the 2D tile-quantization backbone with per-expert LoRA for sub-2-bit MoE. GLoRCQ differs from all four along a single unifying axis: it pools the low-rank U-factor of the compensator across groups of experts drawn from different Transformer layers, and it augments this shared-basis compensator with a threshold-driven FP16 outlier fallback. Under a fair bit budget (2-bit + ~0.16 extra bits), this yields a consistent quality win on Qwen1.5-MoE, Mixtral, and Qwen3-30B-A3B, while remaining compatible with fused VQ4 CUDA kernels for real-quant inference.
